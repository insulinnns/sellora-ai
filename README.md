# Sellora AI

**Создавай карточки товаров, которые продают**

## 1. Что такое Sellora AI

Sellora AI — веб-приложение для продавцов маркетплейсов и небольших интернет-магазинов. Пользователь заполняет форму с характеристиками товара, а Gemini генерирует готовый к публикации контент: варианты названий, краткое и продающее описание, список преимуществ, SEO-ключевые слова и короткий рекламный текст.

## 2. Возможности

- Форма с полной валидацией (название, категория, характеристики, аудитория, тон, длина, доп. пожелания).
- Необязательная загрузка фото товара (JPG/PNG/WEBP) — используется как дополнительный визуальный контекст для Gemini.
- Поиск фотографий товара в интернете по названию карточки.
- Режим «не использовать неподтверждённые характеристики» — AI не додумывает свойства товара.
- Генерация контента через Gemini API, строго в формате JSON.
- Копирование каждой секции результата в один клик, а также копирование всей карточки целиком.
- История последних 5 генераций в `localStorage` — без базы данных.
- Три готовых demo-примера для быстрой презентации.
- Тёмная и светлая тема с сохранением выбора.
- Полностью адаптивный интерфейс (375–430px и шире).
- Понятные сообщения об ошибках на русском языке, без утечки технических деталей.

## 3. Tech Stack

- **Next.js 14** (App Router) + **TypeScript**
- **React 18**
- **Tailwind CSS**
- **Gemini API** через официальный SDK `@google/genai`
- **Zod** для runtime-валидации запросов и ответов
- Без базы данных, без авторизации, без платежей

## 4. Установка

```bash
npm install
```

## 5. Создание Gemini API key

1. Перейдите на [Google AI Studio](https://aistudio.google.com/apikey).
2. Войдите с аккаунтом Google.
3. Нажмите «Create API key» и скопируйте ключ.

## 6. Настройка `.env.local`

Скопируйте пример переменных окружения:

```bash
cp .env.example .env.local
```

Откройте `.env.local` и вставьте свой ключ:

```
GEMINI_API_KEY=ваш_настоящий_ключ
```

Файл `.env.local` уже добавлен в `.gitignore` — он никогда не попадёт в Git.

## 7. Запуск локально

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## 8. Сборка (build)

```bash
npm run build
npm run start
```

## 10. Деплой на Vercel

1. Зайдите на [vercel.com](https://vercel.com) и войдите через GitHub.
2. Нажмите **Add New → Project** и выберите репозиторий Sellora AI.
3. В разделе **Environment Variables** добавьте:
   - `GEMINI_API_KEY` — ваш ключ Gemini.
4. Нажмите **Deploy**.
5. После завершения сборки откройте выданный публичный адрес вида `https://sellora-ai.vercel.app`.

Покупать домен не нужно — стандартного `*.vercel.app` достаточно для демонстрации.

## 11. Переменные окружения (Environment Variables)

| Переменная | Обязательна | Описание |
|---|---|---|
| `GEMINI_API_KEY` | Да | Ключ доступа к Gemini API. Используется только на сервере, никогда не передаётся в браузер. |

Поиск фотографий открывает выдачу Google Images по названию товара. Изображения не вставляются автоматически, чтобы не показывать нерелевантные фотографии.

## 13. Возможные ошибки

- **«Gemini API пока не настроен»** — не задан `GEMINI_API_KEY` в `.env.local` (только в режиме разработки; в production сообщение более общее).
- **«Не удалось создать карточку...»** — проблема с сетью или Gemini API временно недоступен. Попробуйте ещё раз.
- **«Превышен лимит запросов»** — сработал rate limit (10 запросов в минуту с одного IP) либо лимит самого Gemini API.
- **«Gemini вернул ответ в неожиданном формате»** — модель вернула невалидный JSON; попробуйте повторить запрос.
- Ошибка при `npm install` из-за сети — убедитесь, что у вас есть доступ к `registry.npmjs.org`.

## 14. Как изменить модель Gemini

Откройте `lib/gemini-config.ts` и измените значение константы:

```ts
export const GEMINI_MODEL = "gemini-3.8-flash";
```

Это единственное место в проекте, где задаётся имя модели.

## Ограничения (осознанные, для учебного проекта)

- Нет базы данных — история хранится в `localStorage` браузера пользователя.
- Нет авторизации и платежей.
- Rate limiting работает в памяти процесса — на serverless-платформах (Vercel) это простая защита от случайного флуда, а не строгий контроль.
